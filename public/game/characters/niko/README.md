# Assets finales de Niko

El runtime espera un atlas transparente `niko.png` y su descripción `niko.json` en esta carpeta.
El placeholder Canvas permanece activo hasta que esos assets hayan sido producidos y aprobados.

- Atlas recomendado: 768 × 384 px.
- Cuadrícula: 8 columnas × 4 filas.
- Frame: 96 × 96 px.
- Pivot estable: x=48, y=92, centrado en los pies.
- Dirección dibujada: derecha; el runtime invierte horizontalmente para mirar a la izquierda.
- Sin sombras proyectadas ni fondo dentro del atlas.

Frames previstos:

- 0–3: idle
- 4–9: run
- 10–11: jumpStart
- 12–13: jumpUp
- 14–15: fall
- 16–18: land
- 19–20: skid
- 21–22: hurt
- 23–26: death
- 27–30: victory
- 31: reservado
